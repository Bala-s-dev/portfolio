# **App Name**: SecureAI Portfolio

## Core Features:

- AI-Powered Resume Analysis: Utilize Groq API to provide instant resume analysis and feedback.
- End-to-End Encrypted Messaging: Implement a secure messaging system using AES-256 encryption and JWT-secured APIs.
- AI-Generated Mock Interview Questions: Use the Gemini API tool to create tailored interview questions based on resume content and job descriptions.
- Interactive Project Cards: Visually stunning project cards with animated hover effects and tech stack chips.
- Dynamic Skill Grid: Animate a grid showcasing technical skills with hover effects.
- Timeline Experience Section: Display professional experience in a visually appealing timeline format.
- Secure Authentication: Utilize Clerk and OAuth2 for robust user authentication and authorization.

## Style Guidelines:

- Primary color: Dark indigo (#4F46E5) to reflect a deep tech and security focus.
- Background color: Very dark gray (#1A202C) for a modern, professional, dark UI scheme.
- Accent color: Electric violet (#8B5CF6) to provide a vibrant highlight on key elements.
- Body and headline font: 'Inter' for a clean, modern, and readable sans-serif experience.
- Use minimalist, geometric icons to enhance the technical aesthetic.
- Implement a sticky navbar with a blur effect and a smooth scrolling experience to emulate modern SaaS landing pages.
- Use Framer Motion for smooth page transitions, animated section reveals, and interactive hover microinteractions.
